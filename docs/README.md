# Documentation index

Start with the product specification, then the traceability matrix; together
they state what the platform must be and where each requirement is satisfied:

- [Product specification](PRODUCT_SPEC.md) — the authoritative scope: product,
  differentiator, modules, architecture rules, engineering standards.
- [Requirements traceability](REQUIREMENTS_TRACEABILITY.md) — stage-by-stage
  status, dashboard-view matrix, measured metrics, open gaps and the document
  map to the specification's deliverable names.

Read in this order for the underlying detail:

1. [Repository audit](00-repository-audit.md) — what existed before the build,
   the environment constraints and the decisions that followed.
2. [Novelty review](01-novelty-review.md) — prior work, the gap, the falsifiable
   hypothesis and what is explicitly not claimed.
3. [Architecture](02-architecture.md) — components, data flow, storage, capacity
   and failure behaviour.
4. [Threat model](03-threat-model.md) — assets, trust boundaries, adversaries and
   controls with residual risk.
5. [Event contract](04-event-contract.md) — the versioned record every module
   shares, and the feature names normalization understands.
6. [API reference](05-api.md) — authentication surfaces, endpoints, examples and
   error semantics.
7. [Testing and evaluation](06-testing-and-evaluation.md) — suite layout,
   benchmark protocol, measured results, container verification and gaps.
8. [Operations](07-operations.md) — configuration, Compose deployment, sensors,
   backup/restore, upgrade and incident runbooks.
9. [Implementation status](08-implementation-status.md) — what is done, partial
   or deliberately absent, with evidence.

## Keeping documents true

A change to behaviour, configuration, an endpoint or a measured number requires
the matching document to change in the same pull request. Historical records
(`00-repository-audit.md`) describe the state at their stated date and are not
rewritten; later verification is recorded in the testing and status documents.
